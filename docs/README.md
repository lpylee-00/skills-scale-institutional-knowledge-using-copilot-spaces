# OctoAcme Project Management Docs

This directory contains the shared process documentation OctoAcme uses to plan, deliver, and improve projects.

## Project management processes

OctoAcme follows a customer-first, iterative approach with clear ownership, data-informed decisions, and psychological safety. Projects move through five lifecycle stages:

1. **Initiation:** Define the problem, desired outcomes, stakeholders, and initial timeline.
2. **Planning:** Establish scope, resources, milestones, dependencies, backlog, and acceptance criteria.
3. **Execution:** Build, test, review, and iterate on small increments while tracking risks and progress.
4. **Release:** Deploy the work, verify the result, and communicate the release.
5. **Close and retrospective:** Capture learnings, agree on action items, and identify next steps.

The Project Manager coordinates delivery, schedules, risks, and communication; the Product Manager defines outcomes and priorities; and developers, QA, and stakeholders collaborate on implementation, validation, and approvals. The regular cadence includes weekly PM/Product Manager syncs, twice-weekly delivery standups (or an agreed alternative), monthly stakeholder updates, and ad hoc escalations as needed.
